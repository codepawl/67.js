Packs

Make a pack

Install a pack

  1. Unzip it into its own folder inside your packs folder.

    unzip example-starter-1.0.0.zip -d packs/example-starter

  2. Start the MCP server with that folder.

    67js-mcp --packs /absolute/path/to/packs

  3. Check a pack from a 67js checkout.

    npm run pack:check -- packs/example-starter

Addons

Write an addon

An addon runs with the full rights of your page or Node process. Install only addons you trust and read what they do first. The MCP server never loads an addon from a tool call.
