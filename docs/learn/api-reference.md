# API reference

This page lists every export of `67js` and of each addon, with its signature and the comment above it in the source. A script reads the package itself to make the list, so it matches the current code. Each entry links to its source on GitHub.

Import the core from `67js`. Import an addon from its own path, such as `67js/addons/gltf`. If you installed the package without the `67js` alias, start each path with `@codepawlhq/67js` instead.
