- Split the `Test` workflow into parallel jobs (audit, size and tool cost, three unit shards, coverage, package smokes) behind one final `test` job that branch protection keeps requiring, with a shared `.github/actions/setup`. Unit tests now run with Node's built-in coverage; `scripts/coverage-gate.mjs` merges the shard lcov files, writes the job summary and fails when line, branch or function coverage drops more than 0.5 points below `coverage-baseline.json`. `npm run test:isolated` left CI because `node --test` already runs each file in its own process. `publish.yml` calls `test.yml` before publishing and checks `npm view` afterwards.
