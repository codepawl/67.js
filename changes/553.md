- Add `addons/scene-query` and the `scene_walkmap` MCP tool (issue #553). `createSceneQuery(parts)` raycasts a whole loaded scene with each part's world matrix (nearest hit with point, distance, normal, part ID and material), builds the per-part BVH lazily and keeps it, and `walkMap` samples ground height and headroom on a grid. On the Bistro scene a 1 m grid of 12,630 cells matches a Blender sample within 5 cm on 12,619 of 12,629 cells. The MCP server now lists 23 tools. `mesh-query` keeps the last validated matrix per index, so repeated rays against one part skip the matrix checks.
