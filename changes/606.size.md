- goal:lit-box: the renderer lines are the only way to give a part its own shadow and composite behaviour, and hiding or holding out a mesh for a composite is a visible capability.
- goal:gltf-box: same renderer lines as goal:lit-box.
- goal:agent-scene: five node fields and the keyed visible track replace a workaround that films used (#423).
- tool-total: the five node fields appear in every scene tool that takes nodes; the descriptions are one line and the detail sits in scene_capabilities renderFlags.
- tool:scene_create: the five node fields in the node schema.
- tool:scene_apply: the five node fields in the node schema, repeated for add-node and set-node.
- result:scene_capabilities: the renderFlags entry that carries the detail the tool schemas leave out.
