- scene:agent-scene: light, sun, environment and effects tracks need target checks, ranges, a patch per kind and two getters on the scene (about 330 bytes gzip); the code that applies them loads with the motion module (#605).
- scene:agent-scene+lazy: same code, in the lazy motion module (#605).
- goal:agent-scene: a sunset, lamp flicker or rack focus could not be authored before; the core change is the two getters and the pose publish line, the rest sits in the lazy motion module (#605).
- tool-total: one track schema covers four kinds, with the properties of each kind in scene_capabilities motionLook instead of the tool text.
- tool:scene_create: the single lookTrack schema in the motion tracks union.
- result:scene_capabilities: motionLook lists the kinds, ids and properties once, so the tool schemas stay small.
