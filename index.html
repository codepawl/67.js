A scene in a few lines

import { Glaze } from '67js';
import { loadGltf } from '67js/addons/gltf';
import { loadHdri } from '67js/addons/hdri';

const { parts } = await loadGltf('/airport.glb');
const map = await loadHdri('/sky.hdr');
const renderer = new Glaze(canvas, parts, {
  hdr: true,
  ground: false,
  environment: { map },
});

renderer.render({ eye: [58, 31, 84], target: [-8, 3, -18] });

Six scenes at 960x540 on an idle RTX 3060. Each value is the range of the per-scene medians across the scenes. FLIP is the error against a Cycles 4096-sample reference, lower is better. Tier names are working names, and the quality setting that picks one is planned.

Glaze runs the realtime tier in under about 1 ms a frame (0.77 to 0.98 ms), measured with a pixel read. Cook native draws a sample 3.8 to 6.2 times faster than Cycles 5.3 OptiX, but needs more samples for the same noise: 6.6 to 19.0 times Cycles' samples on the three noise-limited scenes (lit-interior, spot-area, light-linking), which is 1.05 to 4.02 times Cycles' time for the sampling alone. On metal, glass and outdoor-hdri Cook does not reach Cycles' error, because the error there is limited by bias, so no ratio is given. Cook cpu needs no card, so VRAM does not apply.

Glaze times are per frame. EEVEE times are one full background render call, including scene sync, with EEVEE ray tracing off and no global illumination. They are not a frame rate comparison. Per-scene tables: bench/tiers on main.
